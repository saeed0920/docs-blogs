# Who Is This Workshop For?

No previous Git experience is required. The workshop starts with version control fundamentals and progresses toward safe, real-world collaboration.

If you've already used commands like `commit`, `push`, `pull`, `branch`, and `merge`, the workshop will also help you understand **why Git works the way it does**, not just **which commands to run**.

---

## This workshop is for you if you:

- Are completely new to Git and version control.
- Have used Git but want a stronger mental model.
- Use or plan to use GitHub or GitLab.
- Want to understand advanced Git workflows.
- Have struggled with merge conflicts or confusing commit history.

---

## What You'll Learn

### Understand Git Internals

Learn how Git stores data, tracks changes, and manages history. A solid understanding of Git's architecture makes advanced commands much easier to use.

### Professional Branch Management

Discover how development teams organize branches and collaborate efficiently on large projects.

### Resolve Merge Conflicts with Confidence

Instead of memorizing conflict resolution steps, you'll learn why conflicts happen and how to handle them effectively.

### Master Rebase

One of the most powerful Git features.

You'll learn:

- When to use **rebase** instead of **merge**
- How to keep commit history clean
- How to safely rewrite history

### Clean Up Commit History

Use advanced tools such as:

- Interactive Rebase
- Squashing commits
- Reordering commits
- Editing commit messages

### Team Collaboration

Learn industry-standard collaboration workflows, including:

- Pull Requests / Merge Requests
- Git Flow
- Code review workflows
- Best practices for working on shared repositories

---

## Workshop Goal

By the end of this workshop, you'll move beyond simply **using Git commands**.

You'll understand how Git works under the hood and gain the confidence to:

- Work efficiently in professional development teams.
- Maintain a clean and understandable project history.
- Solve complex Git problems with confidence.
- Use advanced Git features safely in real-world projects.

Whether you're contributing to an open-source project or working in a software company, this workshop will help you use Git like a professional.
