### سلام

شاید به عنوان اولین پست بلاگ موضوع عجیبی باشه ولی در موردش مینویسم
چند روز پیش یه ریفکتوری داشتم برای یه مجموعه از صفحات
موضوع ازاین قراره که توی این صفحات ما یه سری جداولی داریم که کاستوم هستن و نیازه که بهشون

```css
max-height: 300px;
overflow-y: auto; /* or scroll */
```

بدی
مشکلی که داره اینکه توی صفحات و جاهای مختلف ارتفاع های صفحات فرق خواهد کرد
و خب جدولمون خیلی بد نشون داده خواهد شد

اولین ایده ای که به ذهنم میرسید استفاده از **flexBox** هستش

```css
/* Parent */
display: flex;
flex-direction: column;

/* Child */
flex: 1;
overflow-y: auto;
```


ایده ی بنظر کاملی میاد و درست کار نمیکرد توی صفحات!
و انگار که هیچی اعمال نشده
در اینجا منظور از رفتار درست این است که در همه ی جاها به صورت داینامیک ارتفاع جدول با لایه بالاتریه خودش درست ست بشه و اسکرول هم بخوره درست نه اینکه از پرنتش بزنه بیرون و باعث اسکرول در لایه بالاتری بشه

بعد اینکه مشکل رو به AI گفتم به این نتجه رسیدم

```css
/* Child */
flex: 1;
overflow-y: auto;
min-height: 0; /* !I missed this */
```

البته هنوز ایده ای ندارم که چرا!
