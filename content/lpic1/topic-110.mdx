# Topic 110: Security

This final topic highlights hardening operational elements, scanning for exposed network weaknesses, and utilizing cryptography rules.

## Key Objectives

### 110.1 Perform security administration tasks
* Audit root access profiles, file integrity, and lookups via `su` or `sudo`.
* Set resource limit restrictions inside `/etc/security/limits.conf`.

### 110.2 Setup user security
* Enforce secure password strategies, expiry conditions (`chage`), and audit user activity profiles.

### 110.3 Backup and encrypt communication using SSH
* Establish secure encrypted paths across network targets using OpenSSH.
* Handle RSA/ED25519 identity key generation and safe multi-host access using `ssh-copy-id`.
