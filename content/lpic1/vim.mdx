# Vim & Vim Motions

Vim is the editor you'll find on **every** Linux server, minimal container, and rescue environment.
You don't need to master all of it — you need to be fast enough to open a config file, make a change, and save it without panicking.
This lesson gets you there quickly.

---

## Why Vim feels strange at first

Most editors are always in "typing mode." Vim is different — it has **modes**, and which mode you're in decides what your keys do.

```
┌─────────────────────────────────────────────────────┐
│                      NORMAL                         │
│         (navigate, delete, copy, paste)             │
│                                                     │
│   i / a / o / I / A / O ──────────────► INSERT     │
│                                  Esc ◄──            │
│                                                     │
│   v / V / Ctrl-v ─────────────► VISUAL             │
│                                  Esc ◄──            │
│                                                     │
│   : ──────────────────────────► COMMAND             │
│                          Enter / Esc ◄──            │
└─────────────────────────────────────────────────────┘
```

When you open Vim you land in **Normal mode**. Nothing you type will appear as text — keys are **commands**.
Press `i` to enter Insert mode, type your text, then press `Esc` to go back to Normal mode.

---

## Opening and saving files

```bash
vim file.txt          # open (creates file if it doesn't exist)
vim +42 file.txt      # open and jump to line 42
vim +/error file.txt  # open and jump to first match of "error"
```

Once inside Vim, all file operations are **Command mode** (`:` prefix):

| command     | what it does                              |
|-------------|-------------------------------------------|
| `:w`        | save (write)                              |
| `:q`        | quit (fails if unsaved changes)           |
| `:wq`       | save and quit                             |
| `:x`        | save and quit (only writes if changed)    |
| `:q!`       | quit and discard all changes              |
| `:w newname`| save as a different filename              |
| `ZZ`        | Normal-mode shortcut for `:wq`            |
| `ZQ`        | Normal-mode shortcut for `:q!`            |

> **Tip:** If you're ever stuck and can't quit, press `Esc` a couple of times then type `:q!` and hit Enter.

---

## Modes in practice

```
Open file  →  Normal mode  →  press i  →  Insert mode
type text  →  press Esc   →  Normal mode →  :wq  →  saved
```

Think of **Normal mode as home base**. You always return there before doing anything structural (moving, deleting, copying).

## Moving around — the heart of Vim

In Normal mode the arrow keys work, but using them is slow. The Vim way uses the home row:

```
        k
        ↑
   h ←     → l
        ↓
        j
```

| key | movement                          |
|-----|-----------------------------------|
| `h` | ← one character                   |
| `l` | → one character                   |
| `j` | ↓ one line                        |
| `k` | ↑ one line                        |
| `w` | jump forward to start of next **w**ord |
| `b` | jump **b**ack to start of previous word |
| `e` | jump to **e**nd of current word   |
| `0` | jump to start of line (column 0)  |
| `^` | jump to first non-blank character  |
| `$` | jump to end of line               |
| `gg`| jump to top of file               |
| `G` | jump to bottom of file            |
| `5G`| jump to line 5 (any number + G)   |
| `Ctrl-d` | scroll half-page **d**own    |
| `Ctrl-u` | scroll half-page **u**p      |
| `%` | jump to matching bracket `( ) [ ] { }` |

### Counts multiply motions

Almost every motion accepts a **count** prefix:

```
5j    →  move down 5 lines
3w    →  jump forward 3 words
10l   →  move right 10 characters
```

## Entering Insert mode — 6 ways

| key | where the cursor lands before you type |
|-----|----------------------------------------|
| `i` | before the cursor (**i**nsert)         |
| `a` | after the cursor (**a**ppend)          |
| `I` | at the start of the line              |
| `A` | at the end of the line                |
| `o` | new line below and enter Insert       |
| `O` | new line above and enter Insert       |

## Editing in Normal mode

You don't always need to enter Insert mode to make changes. Normal mode has powerful one-key operators:

### Delete

| key    | what it deletes                  |
|--------|----------------------------------|
| `x`    | character under cursor           |
| `X`    | character before cursor          |
| `dd`   | whole line                       |
| `D`    | from cursor to end of line       |
| `dw`   | from cursor to end of word       |
| `d$`   | from cursor to end of line       |
| `d0`   | from cursor to start of line     |
| `dgg`  | from cursor to top of file       |
| `dG`   | from cursor to bottom of file    |
| `5dd`  | delete 5 lines                   |

### Change (delete + enter Insert)

| key    | what it changes                  |
|--------|----------------------------------|
| `cc`   | whole line                       |
| `C`    | from cursor to end of line       |
| `cw`   | from cursor to end of word       |
| `ci"`  | content **i**nside `"..."` pair  |
| `ca(`  | content **a**round `(...)` pair  |

### Copy and paste

| key    | action                          |
|--------|---------------------------------|
| `yy`   | yank (copy) current line        |
| `Y`    | yank to end of line             |
| `yw`   | yank word                       |
| `3yy`  | yank 3 lines                    |
| `p`    | paste after cursor / below line |
| `P`    | paste before cursor / above     |

### Undo and redo

| key      | action               |
|----------|----------------------|
| `u`      | undo last change     |
| `Ctrl-r` | redo                 |
| `U`      | undo all changes on current line |

---

## Operators + motions = power

Vim's real strength is combining an **operator** with a **motion**:

```
[operator][count][motion]
```

| example  | meaning                                    |
|----------|--------------------------------------------|
| `d3w`    | delete 3 words forward                     |
| `y$`     | yank from cursor to end of line            |
| `c2j`    | change current line + 2 lines below        |
| `d/foo`  | delete from cursor to next match of "foo"  |
| `yG`     | yank from current line to end of file      |

## Search and replace

### Searching

```
/pattern       search forward
?pattern       search backward
n              next match
N              previous match
*              search for word under cursor (forward)
#              search for word under cursor (backward)
```

Set `:set hlsearch` to highlight all matches, `:set incsearch` for live preview as you type.

### Substitution with `:s`

```vim
:s/old/new/          replace first match on current line
:s/old/new/g         replace all matches on current line
:%s/old/new/g        replace all matches in entire file
:%s/old/new/gc       replace all, ask for confirmation each time
:5,10s/old/new/g     replace in lines 5 through 10
```

## Visual mode — select then act

| key      | selects                          |
|----------|----------------------------------|
| `v`      | character-by-character           |
| `V`      | whole lines                      |
| `Ctrl-v` | rectangular block (column mode)  |

After selecting, press an operator:
- `d` — delete selection
- `y` — yank selection
- `>` / `<` — indent / de-indent
- `~` — toggle case

---

## Useful `:` commands

```vim
:set number          " show line numbers
:set relativenumber  " show relative line numbers (great for motions)
:set hlsearch        " highlight search results
:set ignorecase      " case-insensitive search
:set smartcase       " case-sensitive only when query has uppercase
:set tabstop=4       " tab width
:set expandtab       " use spaces instead of tabs
:syntax on           " enable syntax highlighting
:noh                 " clear search highlight
:! ls                " run a shell command without leaving Vim
```

Put these in `~/.vimrc` to make them permanent.

## Muscle-memory drills

The only way to internalize Vim motions is repetition. Work through these in order:

### Drill 1 — Basic survival

Open any text file and practice until it feels natural:

1. Move with `hjkl` — **don't touch the arrow keys**
2. Press `i`, type a word, press `Esc`
3. Press `o`, type a new line, press `Esc`
4. Press `dd` to delete a line
5. Press `u` to undo
6. Save with `:w`, quit with `:q`

### Drill 2 — Word jumping

```bash
# Open /etc/passwd and practice:
vim /etc/passwd
```

- `w` across the fields — count how many words per line
- `b` to jump back
- `dw` to delete a word, `u` to undo
- `5j` to jump down 5 lines
- `gg` → top, `G` → bottom
- `10G` → line 10

### Drill 3 — Find and replace

```bash
vim /etc/hosts
```

- `/localhost` to search, `n` to jump between matches
- `:%s/localhost/LOCALHOST/gc` — replace with confirmation
- `:noh` to clear the highlight
- `ZQ` to quit without saving

### Drill 4 — Copy / paste workflow

1. `V` to select a line in visual mode
2. `3j` to extend selection 3 lines down
3. `y` to yank
4. `G` to jump to end of file
5. `p` to paste

## Common beginner mistakes

| mistake | fix |
|---------|-----|
| Typing when in Normal mode | Press `Esc` then `i` to get back to Insert |
| Can't quit | `Esc` then `:q!` |
| Accidentally deleted text | `u` (undo) immediately |
| Search highlight won't go away | `:noh` |
| Pasted text is indented wrongly | `:set paste` before pasting, `:set nopaste` after |
| Forgot which mode you're in | Look at the bottom-left — it says `-- INSERT --` in Insert mode |

## Quick reference card

```
MOVEMENT          ENTERING INSERT     EDITING
gg  top           i  before cursor    dd   delete line
G   bottom        a  after cursor     yy   yank line
0   line start    I  line start       p    paste below
$   line end      A  line end         u    undo
w   next word     o  line below       Ctrl-r  redo
b   prev word     O  line above       x    delete char
5G  line 5        Esc back to Normal  .    repeat last change

SEARCH            SAVE/QUIT           SUBSTITUTE
/foo  forward     :w    save          :s/old/new/g   line
?foo  backward    :q    quit          :%s/old/new/g  file
n     next        :wq   save+quit     :%s/old/new/gc confirm
N     previous    :q!   discard
*     word fwd    ZZ    save+quit
```
