## Manuals and references

| Resource | Best for |
| --- | --- |
| [GNU Coreutils manual](https://www.gnu.org/software/coreutils/manual/) | Canonical command behavior and options |
| [Linux man-pages](https://man7.org/linux/man-pages/) | System calls, commands, and configuration formats |
| [ExplainShell](https://explainshell.com/) | Breaking down unfamiliar shell commands |
| [TLDR Pages](https://tldr.sh/) | Short command examples before reading `man` |
| [Vim cheat sheet](https://vim.rtorr.com/) | Vim motions and editing commands |

<Callout type="info">
Practice the exact commands in disposable VMs running one Debian-family and one RHEL-family distribution.
</Callout>
