# LPIC-1 Study Guide

This guide covers the **LPIC-1** (Linux Professional Institute Certification — Level 1), the first certification in the LPI Linux certification track.

## What You'll Learn

LPIC-1 validates the ability to perform maintenance tasks on the command line, install and configure a Linux system, and configure basic networking.

## Exam Structure

| Exam     | Code        | Topics                                               |
| -------- | ----------- | ---------------------------------------------------- |
| Exam 101 | LPI 101-500 | Hardware, Boot, Commands, Filesystems, Shells        |
| Exam 102 | LPI 102-500 | Scripting, UI, Admin, Services, Networking, Security |
