## Exam structure

| Exam | Code | Topics |
| --- | --- | --- |
| Exam 101 | 101-500 | System architecture, installation, commands, devices, and filesystems |
| Exam 102 | 102-500 | Shells, desktops, administration, services, networking, and security |

You must pass both exams to earn LPIC-1.
