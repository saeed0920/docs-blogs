# Topic 106: User Interfaces and Desktops

This topic focuses on setting up and navigating graphical interfaces on a Linux server or workstation.

## Key Objectives

### 106.1 Install and configure X11
* Understand the architecture of X11 and display managers (e.g., GDM, LightDM).
* Query and change display parameters.

### 106.2 Graphical Desktops
* Understand common desktop environments (GNOME, KDE Plasma, Xfce) and their general features.

### 106.3 Accessibility
* Know assistive technologies like high contrast themes, screen readers, visual alerts, and sticky keys.
