# Topic 105: Shells and Shell Scripting

This section bridges basic commands and basic system automation using Bash scripts.

## Key Objectives

### 105.1 Customize and use the shell environment
* Manage environment variables (`export`, `env`).
* Edit shell configuration profiles (`.bash_profile`, `.bashrc`).

### 105.2 Customize or write simple scripts
* Structure simple shell scripts using `#!/bin/bash`.
* Implement loops (`for`, `while`) and conditional blocks (`if`, `case`).
* Process user inputs and return exit codes.
