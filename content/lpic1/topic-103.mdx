# Topic 103: GNU and Unix Commands

This heavily tested section covers the everyday core command-line operations essential for any Linux administrator.

## Key Objectives

### 103.1 Work on the command line
* Use single shell commands and one-line command sequences to interact with the OS.

### 103.2 Process text streams using filters
* Use utilities like `grep`, `sed`, `awk`, `cut`, `sort`, and `uniq` to manipulate text output.

### 103.3 Perform basic file management
* Copy, move, delete, and create files and directories (`cp`, `mv`, `rm`, `mkdir`).
* Use wildcards and advanced file globbing.

### 103.4 Use streams, pipes, and redirects
* Master Standard Input (`stdin`), Standard Output (`stdout`), and Standard Error (`stderr`).
* Direct data flows using `>`, `>>`, `<`, and `|`.

### 103.5 Create, monitor, and kill processes
* Run jobs in the foreground and background (`bg`, `fg`, `&`).
* Monitor resources using `ps`, `top`, and termination commands like `kill` and `killall`.

### 103.6 Modify process execution priorities
* Run programs with higher or lower priority using `nice` and `renice`.
