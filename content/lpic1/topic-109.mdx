# Topic 109: Networking Fundamentals

This topic focuses on configuring local interface addresses, routing internet traffic, and basic connectivity tracking.

## Key Objectives

### 109.1 Fundamentals of internet protocols
* Master subnet masks, CIDR blocks, private vs public addresses, and IPv4/IPv6 differences.

### 109.2 Persistent network configuration
* Analyze configuration properties inside `/etc/network/interfaces`, Netplan, or NetworkManager configurations.

### 109.3 Basic network troubleshooting
* Query system connectivity parameters using `ip`, `ifconfig`, `ping`, `traceroute`, `netstat`, and `ss`.

### 109.4 Configure client-side DNS
* Set local lookup endpoints using `/etc/resolv.conf`, `/etc/hosts`, and trace queries via `dig` or `host`.
