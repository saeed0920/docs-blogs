# Topic 108: Essential System Services

This topic handles background services crucial for network synchronization, diagnostic system logging, and automated notification handling.

## Key Objectives

### 108.1 Maintain system time
* Synchronize accurate network time using NTP clients or `chronyd`.

### 108.2 System logging
* Configure and analyze traditional system logging via `syslog`/`rsyslog`.
* Utilize modern Systemd logging tracking using `journalctl`.

### 108.3 Mail Transfer Agent (MTA) basics
* Configure forward loops and basic aliases using Mail engines like Postfix or Sendmail.
