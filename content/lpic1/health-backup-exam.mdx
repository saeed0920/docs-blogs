# Exam — Linux Health Report & Backup

You manage a small Linux machine. Your task is to prepare a workspace, collect a health report, back up sample files, and schedule a daily backup.

This exam checks the commands and decisions needed for that project. It does not execute commands or verify files on your machine.

## Instructions

- **Time:** 20 minutes (self-timed).
- **Questions:** 10 multiple-choice questions; choose one answer for each.
- **Scoring:** One point per correct answer. Pass with **8/10 (80%)**.
- Answer every question before clicking **Submit answers**. Unanswered questions count as incorrect.
- Answers stay editable until submission. Correct answers and explanations appear only after submission.
- Submit your **first attempt** to your instructor before using **Try again**.
- If you try commands, use a disposable Linux VM and work only inside `~/lpic-lab`. No `sudo` is required.

## Scenario

Use Bash on a Debian VM. Your home directory is `/home/student`.

The project uses these paths:

```text
/home/student/lpic-lab/
├── data/          # sample text files
├── reports/       # saved health reports
├── backups/       # compressed archives
├── report.sh      # collects machine information
└── backup.sh      # backs up data/
```

Each question is independent. Assume any files or directories mentioned in it already exist unless the question asks you to create them.
