# Topic 102: Linux Installation and Package Management

This section covers designing a storage layout, installing a Linux distribution, and managing system packages.

## Key Objectives

### 102.1 Design hard disk layout
* Allocate filesystems across partitions (e.g., separation of `/home`, `/var`, and swap).

### 102.2 Install a boot manager
* Install, configure, and maintain bootloaders like GRUB Legacy and GRUB2.

### 102.3 Manage shared libraries
* Locate and manage shared libraries required by executable programs (`ldd`, `ldconfig`).

### 102.4 Use Debian package management
* Manage software packages using `dpkg`, `apt`, and `apt-get` on Debian-based systems.

### 102.5 Use RPM and YUM package management
* Manage software packages using `rpm`, `yum`, and `dnf` on Red Hat-based systems.
