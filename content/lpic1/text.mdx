# Text Processing

One of Linux's greatest strengths is its ability to **chain small, focused commands** together to process text.
Every LPIC-1 candidate must be comfortable reading, filtering, slicing, and transforming plain-text files
from the command line. This lesson walks through each essential tool with real examples.

---

## `cat` — Concatenate and print files

`cat` reads one or more files and prints them to standard output.

```bash
cat /etc/os-release          # print a single file
cat file1.txt file2.txt      # concatenate two files
cat -n file.txt              # print with line numbers (-n)
cat -A file.txt              # show tabs (^I) and line endings ($)
```

`cat` is most useful as the **start of a pipeline** — it feeds content into the next command.

---

## `head` and `tail` — Read the beginning or end

```bash
head file.txt          # first 10 lines (default)
head -n 5 file.txt     # first 5 lines
head -c 100 file.txt   # first 100 bytes

tail file.txt          # last 10 lines
tail -n 20 file.txt    # last 20 lines
tail -f /var/log/syslog   # follow a growing log file in real time
```

`tail -f` is invaluable for monitoring live logs.

---

## `cut` — Extract columns or characters

`cut` removes sections from each line of input. You almost always use it with **delimited files** (CSV, `/etc/passwd`, etc.).

| flag | meaning                           |
| ---- | --------------------------------- |
| `-d` | delimiter character (default tab) |
| `-f` | field number(s) to extract        |
| `-c` | character position(s)             |

```bash
# Extract the username (field 1) and shell (field 7) from /etc/passwd
cut -d: -f1,7 /etc/passwd

# Extract characters 1 through 5 of each line
cut -c1-5 file.txt

# Extract fields 2 through 4 from a CSV
cut -d, -f2-4 data.csv
```

## `sort` — Sort lines of text

```bash
sort file.txt              # alphabetical (default)
sort -r file.txt           # reverse order
sort -n numbers.txt        # numeric sort
sort -k2 file.txt          # sort by field 2 (whitespace delimited)
sort -t: -k3 -n /etc/passwd   # sort passwd by UID (field 3, numeric)
sort -u file.txt           # sort and remove duplicates
```

`sort` is almost always paired with `uniq`.

---

## `uniq` — Filter duplicate adjacent lines

`uniq` **only removes adjacent duplicates**, so always `sort` first.

```bash
sort file.txt | uniq           # remove duplicate lines
sort file.txt | uniq -c        # prefix each line with its count
sort file.txt | uniq -d        # print only duplicated lines
sort file.txt | uniq -u        # print only unique (non-repeated) lines
```

```bash
# Classic pipeline: count word frequency
cat words.txt | sort | uniq -c | sort -rn | head -10
```

---

## `tr` — Translate or delete characters

`tr` works on **characters**, not words or fields. It reads from stdin only — no filename argument.

```bash
echo "hello world" | tr 'a-z' 'A-Z'    # lowercase → uppercase
echo "hello world" | tr -d 'aeiou'     # delete vowels
echo "hello   world" | tr -s ' '       # squeeze repeated spaces to one
echo "hello" | tr 'a-z' 'n-za-m'      # ROT13
cat file.txt | tr '\n' ' '             # replace newlines with spaces
```

| flag | meaning                     |
| ---- | --------------------------- |
| `-d` | delete characters in SET1   |
| `-s` | squeeze repeated characters |
| `-c` | complement (invert) SET1    |

## `wc` — Word, line, and byte count

```bash
wc file.txt              # lines, words, bytes (all three)
wc -l file.txt           # line count only
wc -w file.txt           # word count only
wc -c file.txt           # byte count
wc -m file.txt           # character count (respects multibyte/UTF-8)
```

```bash
# Count how many users are in /etc/passwd
wc -l /etc/passwd

# Count files in a directory
ls /etc | wc -l
```

## `grep` — Search text with patterns

`grep` is one of the most-used commands on any Linux system.

```bash
grep "root" /etc/passwd              # lines containing "root"
grep -i "root" /etc/passwd           # case-insensitive
grep -v "nologin" /etc/passwd        # invert match (lines NOT matching)
grep -n "error" /var/log/syslog      # show line numbers
grep -c "error" /var/log/syslog      # count matching lines
grep -r "TODO" /home/saeed/project/  # recursive search in directory
grep -l "error" /var/log/*.log       # list filenames only
grep -E "^root|^daemon" /etc/passwd  # extended regex (ERE)
grep -w "root" /etc/passwd           # whole-word match
```

### Basic vs Extended regex

| syntax      | `grep`    | `grep -E` / `egrep` |
| ----------- | --------- | ------------------- |
| one-or-more | `\+`      | `+`                 |
| zero-or-one | `\?`      | `?`                 |
| alternation | `\|`      | `\|`                |
| grouping    | `\(...\)` | `(...)`             |

## `find` — Search for files

Unlike `grep`, which searches file _content_, `find` searches the **filesystem tree** for files/directories matching criteria (name, type, size, time, permissions).

```bash
find /etc -name "*.conf"          # find by name (case-sensitive)
find /etc -iname "*.conf"         # case-insensitive name match
find . -type f                    # files only
find . -type d                    # directories only
find / -size +100M                # files larger than 100MB
find /home -mtime -7              # modified in the last 7 days
find /home -mtime +30             # modified more than 30 days ago
find /tmp -empty                  # empty files/directories
find / -perm 644                  # exact permission match
find / -user saeed                # owned by user saeed
find / -maxdepth 2 -name "*.log"  # limit recursion depth
```

 Acting on results: `-exec` and `-delete`

```bash
# Delete all .tmp files
find /tmp -name "*.tmp" -delete

# Run a command on each match ({} = current file, \; ends the command)
find . -name "*.log" -exec rm {} \;

# Batch mode (faster, passes multiple files at once, like xargs)
find . -name "*.log" -exec rm {} +

# Combine with grep: find files, then search their contents
find . -name "*.php" -exec grep -l "TODO" {} \;
```

### Combining criteria

```bash
find / -name "*.sh" -a -perm -u+x     # AND (default): .sh files that are executable
find / -name "*.jpg" -o -name "*.png" # OR: jpg or png
find / -not -name "*.txt"             # NOT
find /var/log -type f -size +10M -mtime -1   # large AND recently modified
```

| flag        | meaning                              |
| ----------- | ------------------------------------ |
| `-name`     | match by filename (case-sensitive)   |
| `-iname`    | match by filename (case-insensitive) |
| `-type`     | `f` file, `d` directory, `l` symlink |
| `-size`     | `+`/`-` size, e.g. `+100M`, `-1k`    |
| `-mtime`    | modified N days ago (`+`/`-`)        |
| `-perm`     | permission match                     |
| `-user`     | owned by user                        |
| `-maxdepth` | limit how deep to recurse            |
| `-exec`     | run a command on each match          |
| `-delete`   | delete matches directly              |

## `sed` — Stream editor

`sed` reads input line by line, applies a script, and prints the result. The most common use is **substitution**.

```bash
# Basic substitution: first match per line
sed 's/old/new/' file.txt

# Global substitution (all matches on each line)
sed 's/old/new/g' file.txt

# Case-insensitive substitution
sed 's/old/new/gi' file.txt

# Edit in place (modify the file directly)
sed -i 's/old/new/g' file.txt

# Delete lines matching a pattern
sed '/^#/d' file.txt          # delete comment lines
sed '/^$/d' file.txt          # delete blank lines

# Print only matching lines (like grep)
sed -n '/error/p' file.txt

# Print specific line range
sed -n '5,10p' file.txt       # print lines 5 through 10
```

### Address forms

```bash
sed '3s/old/new/'        # only line 3
sed '2,5s/old/new/'      # lines 2–5
sed '/start/,/end/d'     # delete from "start" to "end"
```

## `awk` — Pattern scanning and processing

`awk` is a **mini programming language** built for column-based text processing. Each input line is split into fields `$1`, `$2`, … `$NF` (last field), with `$0` meaning the whole line.

```bash
# Print the first and third field of each line
awk '{ print $1, $3 }' file.txt

# Use a custom delimiter (like cut -d)
awk -F: '{ print $1, $7 }' /etc/passwd

# Print lines where field 3 (UID) is greater than 1000
awk -F: '$3 > 1000 { print $1, $3 }' /etc/passwd

# Sum values in column 2
awk '{ sum += $2 } END { print "Total:", sum }' data.txt

# Print line count (like wc -l)
awk 'END { print NR }' file.txt

# Pattern + action
awk '/error/ { print NR, $0 }' /var/log/syslog

# Built-in variables
# NR  – current line number
# NF  – number of fields in current line
# FS  – field separator (set with -F or in BEGIN)
# OFS – output field separator
```

### awk structure

```
awk 'BEGIN { ... } /pattern/ { ... } END { ... }' file
```

```bash
# Example: print header, process, print footer
awk -F: '
  BEGIN { print "Username\tUID" }
  $3 >= 1000 { print $1 "\t" $3 }
  END { print "Done" }
' /etc/passwd
```

## Pipelines — putting it all together

The real power comes from chaining commands with `|`.

```bash
# Top 5 most frequent words in a file
cat file.txt | tr -s ' ' '\n' | tr 'A-Z' 'a-z' | sort | uniq -c | sort -rn | head -5

# List all unique shells in use on the system
cut -d: -f7 /etc/passwd | sort -u

# Count failed SSH login attempts by IP
grep "Failed password" /var/log/auth.log \
  | awk '{ print $(NF-3) }' \
  | sort | uniq -c | sort -rn | head -10

# Find the 3 largest files in /var/log
ls -s /var/log | sort -rn | head -4 | tail -3
```

## Quick reference cheat-sheet

| Command | Primary use                         | Key flags                   |
| ------- | ----------------------------------- | --------------------------- |
| `cat`   | Print / concatenate files           | `-n` `-A`                   |
| `head`  | First N lines                       | `-n` `-c`                   |
| `tail`  | Last N lines / follow log           | `-n` `-f`                   |
| `cut`   | Extract fields or characters        | `-d` `-f` `-c`              |
| `sort`  | Sort lines                          | `-r` `-n` `-k` `-u` `-t`    |
| `uniq`  | Remove/count adjacent duplicates    | `-c` `-d` `-u`              |
| `tr`    | Translate/delete characters (stdin) | `-d` `-s` `-c`              |
| `wc`    | Count lines, words, bytes           | `-l` `-w` `-c` `-m`         |
| `grep`  | Search with regex                   | `-i` `-v` `-n` `-r` `-E`    |
| `sed`   | Stream substitution / deletion      | `s/old/new/g` `-i` `-n` `p` |
| `awk`   | Column processing / mini language   | `-F` `NR` `NF` `BEGIN/END`  |
