# Course Roadmap

Work through the lessons in this order:

1. [HTML Tags and Semantics](/front/html-tags)
2. [Adding CSS to a Page](/front/css-methods)
3. [Flexbox](/front/flexbox)
4. [CSS Grid](/front/grid)
5. [Sass, Bootstrap, and Tailwind CSS](/front/css-frameworks)
6. [CSS Tricks](/front/tricks)
7. [Cascade, Selectors, and Transforms](/front/lastThings)

For each lesson, type the examples yourself, change one value at a time, and finish the practice task. The [course home](/front) lists interactive exercises and project sites.
