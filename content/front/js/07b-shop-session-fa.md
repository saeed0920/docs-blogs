# تمرین: صندوق فروشگاه

[English version](/front/js/07b-shop-session)

تا اینجا با متغیر، شرط، loop، function و array کار کرده‌ایم. امروز با `object` مشخصات یک محصول را نگه می‌داریم و بعد با هم یک صندوق فروشگاه می‌سازیم.

یک `object` برای مشخصات یک چیز است؛ مثلاً نام، قیمت و تعداد یک محصول. یک `array` هم می‌تواند فهرستی از این محصول‌ها را نگه دارد.

## برنامهٔ جلسه

1. مرور function و array
2. آشنایی با object
3. تمرین با هم
4. مسابقهٔ گروهی
5. تست و بررسی راه‌حل‌ها

## ۱. گرم‌کردن

تابع `sumNumbers(numbers)` را بنویسید. با یک loop، مجموع عددهای ورودی را حساب کنید و با `return` برگردانید.

```js
sumNumbers([10, 20, 30]); // 60
sumNumbers([5]);         // 5
sumNumbers([]);          // 0
```

سؤال: اگر به‌جای `return` از `console.log()` استفاده کنیم، چه فرقی می‌کند؟

## ۲. آشنایی با object

هر `object` چند ویژگی یا property دارد. هر property یک نام و یک مقدار دارد.

```js
const product = {
  name: "Notebook",
  price: 50000,
  quantity: 2,
};

console.log(product.name); // Notebook
console.log(product.price * product.quantity); // 100000

product.quantity = 3;
console.assert(product.quantity === 3, "Quantity should change");
```

حالا خودتان امتحان کنید:

1. یک object به نام `student` با دو property به نام‌های `name` و `age` بسازید.
2. نام دانش‌آموز را در console چاپ کنید.
3. مقدار `age` را تغییر دهید.
4. یک property جدید به نام `city` اضافه کنید.

## ۳. تمرین با هم: فهرست محصول‌ها

```js
const cart = [
  { name: "Notebook", price: 50000, quantity: 2 },
  { name: "Pen", price: 20000, quantity: 3 },
];

for (const product of cart) {
  console.log(product.name, product.price * product.quantity);
}
```

نوبت شماست:

- یک محصول دیگر به `cart` اضافه کنید.
- نام و تعداد هر محصول را چاپ کنید.
- مجموع قیمت سبد را بدون تخفیف حساب کنید.

سؤال: چرا `cart` یک array است، ولی هر محصول داخل آن یک object است؟

## ۴. مسابقه: صندوق فروشگاه خراب شده!

صندوق فروشگاه کار نمی‌کند و مشتری‌ها منتظرند. تیم شما باید بخش محاسبه و چاپ رسید را بنویسد.

- دونفره کار کنید و نوبتی کد بزنید.
- فقط JavaScript و console لازم دارید؛ HTML و CSS نمی‌خواهیم.
- استفاده از جزوه و مستندات آزاد است. در طول مسابقه از AI یا راه‌حل آماده استفاده نکنید.
- همهٔ قیمت‌ها به تومان هستند. قیمت و تعداد، عدد صحیح مثبت‌اند.
- سبد ورودی را تغییر ندهید. فعلاً نیازی به بررسی ورودی نامعتبر نیست.

### روش تحویل

این سؤال‌ها برای کلاس طراحی شده‌اند و قالب **LeetCode** دارند. کافی است functionهای زیر را کامل کنید؛ نیازی به خواندن ورودی از stdin ندارید.

- در سؤال‌های A و B، جواب را `return` کنید؛ آن را چاپ نکنید.
- در سؤال C، رسید را چاپ کنید؛ نیازی به مقدار خروجی نیست.
- تمام ورودی‌های داوری با محدودیت‌های سؤال سازگارند.

### سؤال A: روز تخفیف

سطح: Easy | امتیاز: ۲۵

یک مشتری از محصولی با قیمت `price`، به تعداد `quantity` می‌خرد.

اگر مبلغ کل خرید **حداقل ۵۰۰٬۰۰۰ تومان** باشد، مشتری **۱۰٪ تخفیف** می‌گیرد. برای مبلغ کمتر، تخفیفی نداریم.

مبلغ نهایی پرداخت را برگردانید.

#### مثال ۱

```text
Input: price = 50000, quantity = 2
Output: 100000
```

مجموع خرید ۱۰۰٬۰۰۰ تومان است؛ تخفیف ندارد.

#### مثال ۲

```text
Input: price = 100000, quantity = 5
Output: 450000
```

مجموع خرید دقیقاً ۵۰۰٬۰۰۰ تومان است. با ۵۰٬۰۰۰ تومان تخفیف، مبلغ پرداخت ۴۵۰٬۰۰۰ تومان می‌شود.

#### مثال ۳

```text
Input: price = 200000, quantity = 3
Output: 540000
```

مجموع خرید ۶۰۰٬۰۰۰ تومان و تخفیف آن ۶۰٬۰۰۰ تومان است.

#### محدودیت‌ها

- `10 <= price <= 1000000`
- مقدار `price` عدد صحیح و مضربی از `10` است.
- `1 <= quantity <= 1000`
- مقدار `quantity` عدد صحیح است.
- با این ورودی‌ها، مبلغ نهایی همیشه عدد صحیح می‌شود.

#### کد شروع

```js
function getFinalPrice(price, quantity) {
  // Write your code here.
}
```

### سؤال B: سبد خرید

سطح: Easy | امتیاز: ۳۵

یک array به نام `cart` دارید. هر عضو آن یک object با سه property به نام‌های `name`، `price` و `quantity` است.

مبلغ نهایی کل سبد را برگردانید. اگر مجموع خرید قبل از تخفیف **حداقل ۵۰۰٬۰۰۰ تومان** بود، **۱۰٪ تخفیف** بدهید.

تخفیف را **یک بار روی مجموع سبد** اعمال کنید. برای هر محصول جداگانه تخفیف ندهید. اگر سبد خالی بود، `0` برگردانید.

#### مثال ۱

```text
Input: cart = [
  { name: "Notebook", price: 50000, quantity: 2 },
  { name: "Pen", price: 20000, quantity: 3 }
]
Output: 160000
```

دفترها ۱۰۰٬۰۰۰ تومان و خودکارها ۶۰٬۰۰۰ تومان می‌شوند. مجموع خرید به حد تخفیف نمی‌رسد.

#### مثال ۲

```text
Input: cart = [
  { name: "Bag", price: 300000, quantity: 1 },
  { name: "Book", price: 100000, quantity: 2 }
]
Output: 450000
```

مجموع دو ردیف ۵۰۰٬۰۰۰ تومان است؛ پس کل سبد تخفیف می‌گیرد.

#### مثال ۳

```text
Input: cart = []
Output: 0
```

#### محدودیت‌ها

- `0 <= cart.length <= 1000`
- قیمت و تعداد هر محصول، محدودیت‌های سؤال A را دارند.
- مقدار `name` شامل ۱ تا ۳۰ حرف انگلیسی و بدون فاصله است.
- نام محصول‌ها ممکن است تکراری باشد. همهٔ ردیف‌ها را حساب کنید.

#### کد شروع

```js
function getCartTotal(cart) {
  // Write your code here.
}
```

### سؤال C: چاپ رسید

سطح: Easy | امتیاز: ۲۰

برای هر محصول در `cart`، یک خط با قالب زیر چاپ کنید. ترتیب محصول‌ها باید همان ترتیب ورودی باشد.

```text
NAME xQUANTITY: LINE_TOTAL
```

مقدار `LINE_TOTAL` برابر قیمت ضرب‌در تعداد محصول، **قبل از تخفیف** است.

در پایان، یک خط با قالب `Total: FINAL_TOTAL` چاپ کنید. برای محاسبهٔ مبلغ نهایی، تابع `getCartTotal(cart)` را صدا بزنید.

فاصله‌ها و حروف بزرگ و کوچک را دقیقاً مثل مثال بنویسید. خط اضافه یا واحد پول چاپ نکنید.

#### مثال ۱

```text
Input: cart = [
  { name: "Notebook", price: 50000, quantity: 2 },
  { name: "Pen", price: 20000, quantity: 3 }
]
Output:
Notebook x2: 100000
Pen x3: 60000
Total: 160000
```

#### مثال ۲

```text
Input: cart = [{ name: "Bag", price: 300000, quantity: 2 }]
Output:
Bag x2: 600000
Total: 540000
```

#### مثال ۳

```text
Input: cart = []
Output:
Total: 0
```

محدودیت‌ها همان محدودیت‌های سؤال B هستند.

#### کد شروع

```js
function printReceipt(cart) {
  // Write your code here. Reuse getCartTotal.
}
```

### امتیازدهی

۲۰ امتیاز باقی‌مانده برای توضیح درست کد (۱۰ امتیاز) و نام‌گذاری مناسب و خوانایی کد (۱۰ امتیاز) است.

اول درست‌بودن جواب را بررسی می‌کنیم. سرعت فقط وقتی تعیین‌کننده است که امتیاز دو تیم برابر باشد.

کدتان را با سبد خالی و مبلغ‌های کمتر از ۵۰۰٬۰۰۰، دقیقاً برابر با آن و بیشتر از آن تست کنید.

تمرین اضافه، بدون امتیاز: نام محصولی را برگردانید که بیشترین **قیمت واحد** را دارد. برای سبد خالی `null` برگردانید. اگر چند محصول هم‌قیمت بودند، اولین مورد در سبد را انتخاب کنید.

## ۵. سؤال‌های مرور

1. فرق array و object چیست؟
2. چطور یک property را می‌خوانیم و مقدارش را تغییر می‌دهیم؟
3. چرا `getCartTotal` باید مقدار را `return` کند، ولی `printReceipt` باید آن را چاپ کند؟
4. چرا تخفیف را بعد از جمع‌کردن قیمت همهٔ محصول‌ها حساب می‌کنیم؟
5. برای سبد خالی چه خروجی‌ای انتظار داریم؟
