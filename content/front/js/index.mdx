## Rules of the track

1. **Type the code.** Copy-paste teaches nothing.
2. **Every exercise ships an `assert`.** No test framework — see [tools](#the-toolkit).
3. **Read the error before asking.** The message names the file and the line.
4. **AI writes the line, you explain the line.** If you can't explain it, delete it.

## The toolkit

You build one small `js-toolkit/` over the track and reuse it in every project:

```js
// toolkit.js — grows as the track goes
export const $ = (sel, root = document) => root.querySelector(sel);
export const assert = (cond, msg) => {
  if (!cond) throw new Error("FAIL: " + msg);
};
```

Nothing else until a project actually needs it.
