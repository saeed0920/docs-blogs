| Website | Best for |
| --- | --- |
| [Frontend Mentor](https://www.frontendmentor.io/) | Building complete interfaces from realistic designs |
| [CSSBattle](https://cssbattle.dev/) | Short CSS challenges and selector practice |
| [Grid Garden](https://cssgridgarden.com/) | Learning CSS Grid interactively |
| [Flexbox Froggy](https://flexboxfroggy.com/) | Learning Flexbox interactively |
| [freeCodeCamp Responsive Web Design](https://www.freecodecamp.org/learn/2022/responsive-web-design/) | Guided HTML and CSS exercises |
| [MDN Learn Web Development](https://developer.mozilla.org/en-US/docs/Learn_web_development) | Reliable explanations and structured learning |
| [web.dev Learn CSS](https://web.dev/learn/css/) | Modern CSS lessons from browser experts |

Start with a guided lesson, then rebuild the result without looking at the solution. Use browser developer tools to inspect layout, spacing, accessibility, and responsive behavior.
